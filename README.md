# Typeform Clone

A functional Typeform clone: drag-and-drop form builder, a full-screen
animated one-question-at-a-time respondent flow, and a results dashboard
with summary stats.

> Work in progress — this README is a stub during Phase 0 (deploy
> skeleton) and will be filled in with setup instructions, architecture,
> database schema, API overview, and assumptions once the app is feature
> complete.

## Repo layout

- `frontend/` — Next.js (App Router) + TypeScript
- `backend/` — FastAPI + SQLite
